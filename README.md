# 英语乐园 · 人教版 1–4 年级英语学习 H5

一个面向小学生的英语学习小游戏，基于**人教版新起点（一年级起点）1–4 年级**全 8 册 48 单元内容，单文件 H5，手机浏览器打开即用，无需安装。

## 🎮 玩法

| 玩法 | 说明 |
|---|---|
| 🔊 听音选图 | 进入自动播标准音，从 4 张卡片中选出正确的图 |
| 👀 看图识词 | 看图选出对应的英文单词 |
| ✏️ 单词拼写 | 听音 + 看图，点字母把单词拼出来 |
| 🃏 翻牌配对 | 翻牌配「图—词」对子，翻到即朗读 |
| 🎤 跟读打分 | 听示范后跟读，做发音对比反馈 |

## ✨ 特色

- **带读音**：进入题目自动朗读，点任意答案/卡片即点即读（浏览器原生英文语音引擎，Web Speech API）。
- **闯关外壳**：选年级 → 单元地图（带星星）→ 过关得 ⭐ 解锁下一单元，进度自动保存。
- **简洁界面**：圆角大卡片、马卡龙配色、超大字号、移动端优先。
- **离线可用**：单文件 `index.html`，零依赖，可下载后直接打开。

## 🛠 技术说明

- 纯前端单文件（`index.html`），无构建步骤、无第三方依赖。
- 语音使用浏览器 `SpeechSynthesis` API（英文朗读），右上角 ⚙️ 可关闭发音、调节语速。
- 进度使用 `localStorage` 本地保存。
- 跟读功能依赖浏览器麦克风与语音识别，部分环境不支持时可「跳过」继续，不会卡关。

## 📦 本地运行

直接双击 `index.html` 用浏览器打开即可；或起一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

人教版新起点（一年级起点）1–4 年级：一上、一下、二上、二下、三上、三下、四上、四下，共 8 册 48 单元，每单元含核心词汇（英文 + 中文 + 图标）与重点句型，数据集中在 `index.html` 顶部的 `DATA` 对象，方便增改。
